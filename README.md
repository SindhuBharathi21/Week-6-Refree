# Week 6 – The Referee

## Problem Statement
Choosing the right AWS compute service is difficult due to trade-offs in cost, scalability, and management.

## Solution
This tool compares EC2, Lambda, and ECS based on user constraints and explains pros, cons, and trade-offs.

## How It Works
1. User provides budget, scalability, and management preference
2. Tool evaluates each option
3. Trade-offs are explained clearly

- Python
